# 尼龙 Wiki

公开的战术尼龙装备知识库，面向尼龙萌新、准备入坑的小白与围观者，老手也能当工具书查。

**在线访问**：https://yongshoushou.github.io/nylon-wiki/

## 覆盖内容

| 分区 | 词条 |
|---|---|
| 入门 | 新手入门指南 · 术语表 · 考证资料源 |
| 材质与工艺 | 面料知识 · 织带与扣具 · 缝合工艺 · MOLLE 与挂载系统 |
| 装备品类 | 浪人腰带 · 棘轮式腰带（避坑） · 承载系统 · 挂载包体 · 搭配原则 |
| 造型还原党 | 流派方法论 + 真兵图鉴：CAG / 三角洲 · USSS CAT · SFG 绿色贝雷帽 |
| 造型自设党 | 世界观与色彩锚点方法论 |
| 下场竞技党 | 防护 / 轻量 / 快取 / 透气优先级与合规提示 |
| 保养与交易 | 保养清洗 · 二手交易避坑 |
| 品牌导航 | 国际一线 / 国际性价比 / 国产精工与复刻 |

## 仓库结构

```
index.html   单文件自包含站点（GitHub Pages 直接部署这份）
data.js      词条数据源（增删词条只改这个文件）
build.js     构建脚本：改完 data.js 执行 node build.js 同步进 index.html
```

## 如何贡献词条

1. 打开在线站点，进入「✍ 添砖加瓦」编辑页
2. 填写/选择词条内容，右侧实时预览
3. 点「生成代码」→ 复制产出的词条对象
4. 通过 Issue / 私信等方式发给维护者，合并把关后上线

贡献原则：只写可通用的知识，不写个人数据；不确定的信息标注「待核实」。

## 本地运行

无需构建，直接用浏览器打开 `index.html` 即可；或本地起任意静态服务器。

修改词条流程：编辑 `data.js` → 执行 `node build.js` → 提交 PR 或 Issue。
